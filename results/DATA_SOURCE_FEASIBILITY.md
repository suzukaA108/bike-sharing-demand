# 近期数据源可行性调查

核验日期：2026-10-26，实施状态更新于 2026-11-08。本报告记录数据源选型和已完成的全量实施结果。

## 结论与建议

已采用 **2024—2025 年 Citi Bike JC 发布服务范围行程＋独立历史天气＋当地日历特征**。这不是 NYC 全城数据，也不是未经筛选的 Jersey City 行政市界数据。

该路线保留近期性和多源整合能力，体量适合本机处理。2024—2025 两个完整年份已完成下载、审计、准备和模型评估。

GB、MB 在本表使用十进制。大小来自官方对象 Size，不是完整下载测速。文件名不能全部按固定模板生成：例如 JC 2025 年 10 月使用 `JC-202510-citibike-tripdata.zip`，其他多数月份使用 `.csv.zip`。下载清单应来自索引。

官方说明指出较大月份压缩包可能含多个 CSV，计算月总量必须读取所有有效 CSV，排除 `__MACOSX` 元数据。官方还说明已经进行服务行程、测试站点和部分短行程过滤；实际异常仍需审计，不能将说明当作数据绝对无误的保证。

### 单月样本检查

样本：https://s3.amazonaws.com/tripdata/JC-202501-citibike-tripdata.csv.zip

- 内存下载成功，压缩 1,742,971 字节；主 CSV 解压 11,081,709 字节。
- 50,611 条记录；本样本内 `ride_id` 没有重复。后续全年审计发现跨 CSV 重复，因此最终按 ride ID 去重并处理冲突。
- 字段包含 ride_id、rideable_type、started_at、ended_at、起终站点名称和 ID、起终经纬度及 member_casual。
- `started_at`、起点站点、起点坐标在样本中无空值；部分终点字段缺失。按出发计数时不能无条件删除终点缺失行。
- 起始时间最小为 2024-12-31 23:46:42.360，最大为 2025-01-31 23:53:42.476。月份文件包含越界出发时间，必须按实际时间过滤、聚合，并检查相邻月份边界。
- 样本坐标范围约纬度 40.707—40.755、经度 -74.087—-74.024。该范围不能替代正式区域定义。
- 时间戳样本没有显式 UTC 偏移；仅此样本不能证明跨夏令时时刻如何编码。

## 天气可行性与限制

官方文档：https://open-meteo.com/en/docs/historical-weather-api

接口：https://archive-api.open-meteo.com/v1/archive

已成功查询区域附近坐标（40.71, -74.04）2024-01-01 至 2024-01-03 的逐小时温度、相对湿度、降水与风速，返回 72 小时；2025 年两日小样本也成功。请求无需提供 API Key。

这只证明接口和小范围数据可取，不代表已核验两年全量完整性、最终授权或请求限制。Open-Meteo 历史产品应按具体产品核对模型来源、再分析性质、空间分辨率和延迟，不能称作当地站点的实时实测值。

**关键假设**：即使只输入时间戳早于目标小时的历史天气，也不意味着这些数值在当时已经发布。若采用再分析产品，应明确这是历史回测的信息可用性假设；真实部署可能需要有延迟的观测或其他天气接口。可替代调查方向为 NOAA 小时站点观测，但本轮未完成站点覆盖和缺测核验，不推荐立即据此实施。

天气最终建议使用 UTC 响应与 UTC 主时间轴连接，再生成当地日历特征；不依赖响应中单个固定 utc_offset_seconds 转换全年时刻。夏令时切换需单独测试。

## 已执行的处理约定与剩余限制

1. 区域固定为 JC 发布服务范围，以文件中所有有效出发记录为准；不作行政边界过滤。
2. 全年识别 151 条秋季重复本地时间记录并排除；两个回拨小时对应的 4 个 UTC 目标时刻不评分。
3. 24 个月文件完整下载并校验；2,055,155 条原始行程中有 24 条重复 ride ID，其中 10 个 ID 存在时间戳冲突，冲突 ID 整体排除。全量审计无无效 started_at。
4. 2024 为开发/滚动验证，2025 为留出期。评估完成后不再调参；早期曾查看过一次留出期指标，因此不称完全盲测。
5. 小样本和全年小时级天气连接已验证；逐小时天气缺测的历史处理在特征流水线与各折有效样本中体现。
6. 发布遵守上游数据使用政策：不提交原始归档、逐行行程或逐小时预测明细；公开汇总指标、审计说明和图表。Open-Meteo 的归属、非商业使用和 API 限制见官方条款链接，商业用途需重新确认。

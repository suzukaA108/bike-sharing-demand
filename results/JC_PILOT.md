# JC 数据迁移试验：2025 年 1 月

目标区域口径已确定为 Citi Bike 官方 `JC-` 月文件发布范围，预测每小时出发次数；不等同于纽约全城或 Jersey City 行政市界内需求。样本只用于验证数据连接，不报告模型效果。

## 样本与审计

- 下载 2024-12、2025-01、2025-02 三个月官方 JC 压缩文件，合计约 5.36 MB；均记录 SHA-256。
- 三文件共 150,699 条行程。按实际 `started_at` 筛选后，2025 年 1 月有 50,611 条，其中 2 条来自 2 月文件，50,609 条来自 1 月文件。
- 样本没有无效起始时间、1 月缺失 `ride_id` 或跨文件重复 `ride_id`；这不代表其他月份也没有。
- 1 月按当地墙上时钟汇总得到 744 个小时，其中 5 小时为零；需在全量审计时进一步核实源文件覆盖情况。
- 逐小时请求天气时必须覆盖纽约当地 1 月末对应的 UTC 2 月 1 日，否则漏掉末尾 5 小时。已改用当地月份边界推算 UTC 请求日期，744 个小时都匹配到温度、相对湿度、降水和风速，4 列均无缺测。
- 天气网格坐标实际解析为 (40.738136, -74.04254)，不代表覆盖整个 JC 发布服务范围的所有微气候。

## 可复现命令

从项目根目录，使用安装了 `requirements.txt` 的 Python：

```bash
python -m src.jc_data --download
python -m src.jc_weather --month 2025-01
python -m unittest discover -s tests -v
```

输入原始压缩包和逐小时天气连接结果保存在 Git 忽略目录；可公开的审计结果在 `results/metrics/jc_pilot_audit.json`、`jc_weather_pilot_audit.json` 和 `jc_pilot_hourly.csv`。

## 当前限制

- 原始 `started_at` 不带明确 UTC 偏移。1 月样本避开夏令时转换；**不得将试验脚本的本地化策略直接扩展到 11 月重复小时**。
- Open-Meteo 历史值不一定在预测当时已发布，天气实时可用性与授权需进一步核查；当前只是离线多源对齐试验。
- 尚未下载/检查 2024—2025 完整数据，未决定新数据集的训练、验证、测试切分，没有开展模型训练。
